# Popstiche Ops

This site documents the design and operation of a lightweight system for running an event-based retail business.

## What this project demonstrates
- Docs-as-code workflow (MkDocs + GitHub Actions)
- Structured operational documentation (workflows, roles, terminology)
- System design (data model, architecture)
- Project management practices (charter, backlog, risks, status tracking)

## Key Sections
- **Project** — planning, decisions, and progress tracking
- **Product** — operational workflows and roles
- **System** — data model and architecture
