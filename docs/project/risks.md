# Risks

## Current Risks

### Over-engineering early
- **Risk:** Designing beyond actual operational needs
- **Mitigation:** Validate workflows during real events before expanding scope

### Misalignment between docs and real usage
- **Risk:** Documentation diverges from actual process
- **Mitigation:** Update docs immediately after each event

### Data capture inconsistency
- **Risk:** Incomplete or inconsistent logging during events
- **Mitigation:** Keep workflows simple and repeatable
